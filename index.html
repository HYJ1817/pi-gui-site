03 架构 本机链路

不接管 Pi，
只把它放到窗口里

Pi GUI 是 Electron 桌面应用，界面通过本机端口连接本地服务， 再由服务以官方 RPC 协议驱动独立的 Pi 子进程。全局 Pi 安装不被修改。

  • 01

    独立安装

    依赖你本机已安装的 Pi Coding Agent，版本与配置由你掌控。

  • 02

    回环访问

    界面与服务走本机回环端口，不对公网暴露。

  • 03

    进程治理

    单个 Pi 子进程与桥接，停止、恢复与清理都有明确边界。

05 对照 同一套 Pi

终端直接跑，
还是放进窗口

两边驱动的是同一个 Pi，协议也是同一套 RPC。区别只在操作面：命令行轻、可脚本化；窗口把会话、变更与任务摊开。

TERMINAL

命令行里的 Pi

  • 一条命令就能开始，占用最低
  • 天然适合脚本、管道与批量任务
  • SSH 进远程机器照样能用
  • 变更靠自己敲 git diff 核对
PI GUI

窗口里的同一个 Pi

  • 侧栏按项目组织会话，可搜索与分叉
  • 右栏逐文件 Diff，改动可受控撤销
  • 工具调用逐条展开，Thinking 可回看
  • 任务与验证证据留在同一处

短活、脚本、远程调度留在终端；长会话、多项目、要盯 Diff 的活放进窗口。

06 本地优先 数据边界

数据留在你的机器上

Electron + Node.js 通过本机 RPC 连接 Pi，项目与会话保存在本地， 不要求云端账户，不上传使用遥测。使用云端模型时，请求直接发往你所配置的供应商。

Windows 安装包目前尚未接入正式代码签名（正在申请 SignPath Foundation 的开源免费签名）。因此 Windows 可能提示 「未知发布者」——请只从 官方 GitHub Releases 下载，并核对 Release 自带的 SHA256SUMS.txt 签名政策说明 ↗。

07 快速开始 约 10 分钟

五步开始工作

1

安装 Node.js 22.19+

Pi 与 Pi GUI 都依赖 Node.js，安装 LTS 版本 后验证：

node -v
2

安装 Pi Coding Agent

全局安装本机使用的 Pi（也可改用 Pi 官方安装器，可自动装缺失依赖）：

npm install -g @earendil-works/pi-coding-agent
pi --version
3

配置模型供应商

首次运行需完成至少一个供应商的认证，之后才能开始对话： 在 供应商说明 与 Pi 使用文档 有完整指引。

cd 你的项目目录
pi
4

下载并运行 Pi GUI

从下方的 下载区 获取 Windows 版本。下载后可通过 Release 自带的 SHA256SUMS.txt 校验完整性。

安装版和便携版有什么区别？+

两者功能一致：安装版（Pi-GUI-Setup-*.exe）安装到当前用户目录 （%LOCALAPPDATA%\Programs\Pi GUI），可从开始菜单启动，支持应用内更新； 便携版（Pi-GUI-*-portable.zip）解压后直接运行 Pi GUI.exe，不写注册表，适合免安装或 U 盘使用。

5

创建项目，开始对话

打开 Pi GUI，添加本地项目文件夹，在输入框描述任务，右侧面板检查文件变更与执行结果。

安装不顺利？先看这几条+

· 提示 pi 不是内部或外部命令：npm 全局目录不在 PATH，重开终端或检查 npm prefix -g。

· node -v 低于 22.19：升级 Node.js，或改用官方安装器由其自动处理。

· Windows 提示「未知发布者」：安装包尚未接入正式签名，请从官方 Releases 下载并核对 SHA256SUMS.txt（见下方下载区）。

· npm 报网络错误：确认能访问 npm 源，企业网络需配置代理后重试。

10 常见问题 4 条

你可能想问

Pi GUI 是免费的吗？+

免费。项目以 MIT 协议开源，安装包不收费；模型调用产生的费用由你所配置的供应商收取。

需要注册账户吗？+

不需要云端账户。项目与会话保存在本地，不依赖 Pi GUI 的服务器。

必须先安装 Pi 吗？+

是。Pi GUI 通过官方 RPC 协议驱动本机独立安装的 Pi Coding Agent，完整流程见上方「快速开始」。

支持哪些系统？+

当前发布提供 Windows 安装版与便携版，界面与操作以桌面端为准。
